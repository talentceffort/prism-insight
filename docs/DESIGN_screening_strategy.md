# 스크리닝 전략 설계 — 거래대금 확인 + LLM 게이트 (KR)

> 상태: **진입 1차필터 = 개념 확정 / 매도 = 미정 / 배선 = 미착수.** 포크(dragon1086) 재조형.
> 결정·근거가 바뀌면 아래에 한 줄 추가. 상세 백테스트 = [DESIGN_pullback_strategy.md](DESIGN_pullback_strategy.md),
> sim 인프라 = [DESIGN_sim_paper_trading.md](DESIGN_sim_paper_trading.md).

## 목표
포크 기반 흐름(급등 트리거 → LLM 분석 → 알림)을 재조형한다:
**코드 1차필터(거래대금으로 확인된 이동) → LLM이 상승여력·축적/분배 판단 → 통과분만 알림**(Phase-1 관찰) → 후에 매수(Phase-2).
**알파는 LLM의 선택 판단에, 기계는 깔때기 + 진입/매도 타이밍.**

## 결정 (왜 이렇게 — 방향키)
- **[핵심] 알파 = LLM 선택.** 기계 단독 선택은 약함이 백테스트로 확인됨(아래 근거). 그래서 LLM이 판단한 종목만 진입.
- **1차필터 = "거래대금으로 확인된 이동"** — 급등 *대신* 거래대금이 아니라, **거래대금 폭발로 확인된 급등**. (급등+거래대금無 = 얇은 펌프 배제)
- **거래대금 폭발은 "일찍 진입"이 아니라 "품질 확인"용.** "조용한 축적(돈 먼저, 가격 나중)"은 한국 데이터상 드묾(15일 검증) → 거래대금은 이동의 *진위 확인* 지표로만.
- **LLM 게이트 = 기존 6에이전트 + Buy Specialist.** 판단 = "축적/분배/순환매 구분 + 상승여력". **거부만(발굴 X)** → 1차필터가 천장을 정함.
- **과적합 회피 규칙(중요):** 필터를 조일 땐 **용량(top-K)·위생(동전주/관리/최소거래대금 제외)** 만. **예측용 마법 숫자 임계값 금지**(2025에 맞추면 OOS 사망 — 이번 세션 반복 확인).
- **매도 = 미정, 그리고 지금 보정 불가.** 출구는 포지션 성격에 맞춰야 하는데 **LLM이 뭘 뽑는지 데이터가 없음** → 지금 파라미터 정하면 진공 튜닝(과적합). **순서: 엔트리 먼저 돌려 픽 데이터 확보 → 픽 성격 보고 → 그때 매도 설계·보정.** 방향만: 소스별·다중TF(주봉/일봉), 단일 고정규칙 실패 확인. Phase-1 측정은 `analysis_performance_tracker`(7/14/30일)로 충분(실 매도 불필요).
- **검증 = 전방 sim A/B.** LLM 판단은 백테스트 불가(룩어헤드). `mechanical-only` vs `+LLM` 나란히.

## 확정된 진입 1차 필터 (개념)
```
(의미있는 이동) AND (거래대금 폭발 = 실참여) AND (위생: 동전주·관리종목·최소거래대금 하한)
   → spike 배수로 랭킹 → 상위 K개(하루 ~20개, LLM 처리 가능)
   → LLM 게이트(상승여력/축적·분배 판단) → 통과분만 알림
```

## 근거 (이번 세션 백테스트에서 배운 것 — 요약)
- **눌림목 v2.1**: 얇은 엣지. per-trade OOS +0.94%지만 **10슬롯 포트에선 안 잡힘**(승률 낮아 소수 승자 못 담음). per-trade ≠ portfolio. (상세: pullback 문서)
- **월봉 10M 추세**: 전기간 +44~793%지만 **생존편향+2025 반도체 멜트업**이 대부분. 인샘플/OOS 격차 크고, 무엇보다 **한국 초변동장에서 출구 관리 불가**(MDD −37~62%, 느린 출구=폭락 게워냄, 빠른 출구=휩쏘). 트레일 스윕에 스윗스팟 없음.
- **거래대금**: "조용한 폭발"은 15일 내내 드묾 → 거래대금 = *품질 확인* 지표(일찍 아님).
- **지수 10M 타이밍**: 한국선 약함(국면필터로 부적합) → 블렌드에서 뺌.
- **종합**: 기계 단독으론 한국에서 견고한 엣지 안 나옴 → 알파는 LLM 선택 판단(전방 검증 대상).

## 안 하는 것
마법숫자 임계값 튜닝(과적합) · 거래대금으로 "조용히 일찍" 진입(데이터상 없음) · LLM 스크리닝 백테스트(룩어헤드로 불가) · 트레일 단일고정 출구(휩쏘).
