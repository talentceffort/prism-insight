# 눌림목 전략 설계

> 상태: **설계 중** (백테스트 전). 결정이 바뀌거나 새로 생기면 아래 **결정**에 한 줄 추가.
> 별개 문서: sim(페이퍼 매매 인프라)은 [DESIGN_sim_paper_trading.md](DESIGN_sim_paper_trading.md).

## 목표
거래대금 상위 유니버스에서 **상승추세 종목의 눌림(되돌림)을 매수**하고 칼같이 손절한다.
엣지는 **스크리닝(상승추세 필터)** 에 있음(유튜버 관찰 기반). 진입/손절은 단순하게, 값은 데이터로.

## 결정 (왜 이렇게 — 방향키)
- **스크리닝 필터 후보** = 상승추세 + 펌프제외 + 섹터강도(주도섹터) + 유동성(거래대금).
  구체 값(5일 임계·섹터 가중 등)은 **하드튜닝 X → 백테스트로 결정**. prism의 매크로 섹터리더/모멘텀이 이미 상당수 커버.
- **진입** = 지지선(이평선 or 피보, 설정가능)에서 **"그냥 진입"(v1)**. 거래대금 상위=빠른 종목이라
  반등확인 기다리면 놓침 → **손절이 곧 확인** 역할. (확인 후 진입은 백테스트 비교용)
- **손절** = 지지선 하단. 폭(−1/−2/−3%·ATR)은 **백테스트 스윕**. 진입가 −1%는 노이즈에 과잉 손절 위험.
- **매도** = 목표가 / 시간(1~3일) / 트레일링 중 — **백테스트로 결정**.
- 진입·손절·매도는 **한 세트로 백테스트**(조합 스윕). 진입/손절이 성패 대부분.
- **검증 분리**: 결정론층(스크리닝룰+진입+손절+매도) = **KRX 백테스트** / LLM 스크리닝의 추가가치 = **sim 전방**.

## v1 룰 (백테스트 시작값 / 스윕 범위)
값은 출발점일 뿐 — 백테스트가 스윕해서 실제 값을 정한다.

| 요소 | v1 시작값 | 스윕 범위 |
|---|---|---|
| 유니버스 | 거래대금 상위 100 | 50 / 100 |
| 스크리닝(상승추세) | 20일선 위 AND 5일 수익률 > 0 | 5일 임계 0 / +3 / +5% |
| 펌프 제외 | 오늘 등락 < +15% | +15 / +20% |
| 지지선(진입 기준) | 5일 이동평균선 **(전일 기준 — 룩어헤드 방지)** | 5 / 10 / 20일 |
| 진입 | 그날 저가 ≤ 지지선 → 지지선에서 체결 | (v2: 반등확인) |
| 손절 | 진입가 −2% | −1 / −2 / −3% / ATR |
| 매도 | +5% 익절 OR 3거래일 후 종가 (먼저 오는 것) | 목표 3/5/8% · 보유 2/3/5일 |
| 비용 | sim_broker (틱 슬리피지 + 수수료 0.015% + 매도세 0.2%) | 고정 |
| 섹터 필터 | v1 제외 | (v2 추가) |

구현 규칙: **손절·목표 같은 날 둘 다 닿으면 손절 먼저**(보수적), **walk-forward** OOS.

## 안 하는 것
LLM 스크리닝 백테스트(학습컷오프 룩어헤드로 불가 → 전방 sim) · 실주문 · 정밀 체결 재현.
