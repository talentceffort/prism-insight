# sim 페이퍼 트레이딩 설계

> 상태: **설계 확정 대기** (구현 전). 결정이 바뀌거나 새로 생기면 아래 **결정**에 한 줄 추가.

## 목표
LLM 자동 스크리닝이 실제로 오르는 종목을 고르는지를, 브로커 없이 **로컬 페이퍼**
(실제 KRX 가격 + 가상 체결 + 현실 비용)로 **전방 검증**한다. 판단은 정직한 순자산 기준 수익률/MDD로.

## 결정 (왜 이렇게 — 방향키)
- `default_mode`에 **`sim`** 값 추가. 별도 `SIM_TRADING` 플래그는 안 만든다 (개념 중복 방지).
- 실행은 **매수/매도 디스패치 1곳**에서만 분기. sim이면 **KIS를 아예 안 부른다** (저수준 안 건드림).
- 가격은 **KRX**(task B 폴백)에서 받는다 → sim은 KIS 계좌 불필요.
- 비용 = **틱(호가단위) 슬리피지 + 수수료 0.015%/편도 + 매도세 0.15%** → `sim_broker.py` (완성, 테스트 8/8).
- 자본 **1천만 / 10슬롯 균등 = 종목당 100만**.
- **가상 sim 계좌 1개**(`account_key="sim:..."`)로 기존 계좌-DB 로직 재사용.
- equity = 현금 + Σ(수량×현재가) → `equity_tracker` 스냅샷 → 정직한 수익률/MDD.
- 스크리닝 v1 = **자동(LLM)**. 하이브리드(사람 승인)는 후속.

## 안 하는 것
정밀 체결 재현(고정 틱=근사) · 눌림목 진입(별도 KRX 백테스트) · 실주문.
